Usage:
  gust <source.gst>
  gust --backend cranelift [-o <output>] <source.gst>

Backends:
  cranelift  Compile to one native executable (default).
  The generated-C backend was REMOVED in Phase 24; mir-to-c and c are rejected.
  Bootstrap C retirement is separate and deferred to Phase 25.
Options:
  --backend <cranelift>            Select the backend explicitly.
  -o <output>                     Optional Cranelift output; defaults to the source stem.
  -h, --help                      Show this help and exit.

Native backend driver:
  Set GUST_NATIVE_BACKEND_DRIVER to an absolute executable path, or install
  gust-native-backend next to gust. There is no PATH search, auto-build, or
  fallback to MIR-to-C.
